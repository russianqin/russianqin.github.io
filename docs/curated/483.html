一、什么叫约炮

约炮，是成年男女双方自愿发生、不承担恋爱关系和排他承诺的一次或多次性行为。
约炮可以只发生一次，也可以发生很多次。
它不包括打着恋爱的旗号骗女生上床，也不包括嘴上承诺感情、实际只想发生身体关系。
是否戴套、是否接受内射、愿意发生哪些行为、约完以后还要不要再约，都由双方共同决定。安全套须提前准备，无套和内射这种风险更高的行为，可临时决定或者提前说清楚。
约炮不承担恋爱关系的承诺，也默认不存在一对一的关系承诺。
但没有感情承诺，不代表两个人之间完全没有感情。你们可以喜欢彼此，可以关心彼此，也可以相处得很好，只是没有答应要成为男女朋友，更没有答应要对彼此的人生负责。
有些长期炮友会因为安全问题，约定只和彼此发生性关系。这种身体上的一对一同样可以存在，但它必须是双方主动说清楚的结果，不能靠任何一方自己默认。
现实里，单身女性、有男朋友的女性、已经结婚的女性，都可能发生约炮行为。
隐瞒和出轨不在这篇文章的讨论范围内，只要双方自愿即可。这也代表已经有伴侣的人不一定需要说明自己的关系状态（但是有时候和人妻约炮确实更刺激）。

你只能和本来就想约炮的女生约炮。

如果一直遇不到怎么办？

退回上一步，继续去约会软件、酒吧、朋友局和旅行场景认识更多人。扩大认识同类需求者的数量，别训练自己怎样改变一个不想约炮的人。

3. 女生为什么会约炮

按照我自己的观察，20—25 岁的女生约炮，很多时候来自好奇。

她可能从来没有约过，想知道约炮到底是什么感觉；也可能正在探索性生活；还有一部分人就是欲望比较强。

25—30 岁，甚至 30—35 岁的女生，动机通常会变成释放压力。

这个年龄段的人工作压力更大。如果她暂时没有进入稳定关系，也不想把大量时间和精力投入恋爱，约炮会成为一种更加直接的选择。

还有一类，是已经在恋爱关系里却长期得不到满足的女生。

按照我的判断，这里面 70% 是情感上不满足，30% 是身体上不满足。

女人的情感和身体通常连在一起。她在关系里长期感受不到关注、爱和刺激，身体需求也很难被原来的伴侣满足，于是她会向外寻找新的刺激。

4. 第一次见面怎么选地方

第一次见面，我更建议选择灯光偏暗、相对安静、离其他客人远一点的酒吧或餐厅。

提前看大众点评时，不要只看饮料和装修。看看店里有没有角落、卡座或半封闭的位置，能不能让两个人自然坐得近一点，安静地说话。

稍微嘈杂一点也可以。你们需要靠近才能听清对方讲话，距离会自然拉近。只要她向后躲、主动拉开距离，你就应该看懂这个信号。

第一次尽量不要直接约去特别拥挤的蹦迪场所。人太多、声音太大，根本没有办法正常建立吸引力。民谣酒吧可以，但不要选择挤到连话都听不清的地方。像大兵的小屋这种过于拥挤的场景，就不适合第一次见面。

5. 怎样提出转场

如果女生是来你的城市旅游，她通常已经订好了酒店。

气氛合适的时候，你可以开玩笑地问她：“要不要回酒店继续喝一点？我去买酒。”

如果你们都住在同一个城市，而你自己住，也可以邀请她去你家继续喝，或者说：“我家有只猫，要不要去看看？”

这种理由老掉牙，甚至有点拙劣，但这反而没有问题。

拙劣理由的作用，就是让双方都听懂这句话背后的意思。她愿意就会答应。表现你的有趣，同时给她留下轻松拒绝的空间。

第一种，她不喜欢你。真人和照片差别太大，或者你们聊天实在太尴尬，她不想继续。这个时候基本就没有下文了，接受结果就可以。

第二种，她今天确实不方便，或者第一次见面不想这么快。她可能想先见见你，过几天再决定要不要和你去酒店。这完全正常。

第一次见面能够接吻就已经可以。你没有必要把发生性关系当成一个必须完成的 KPI。

别把拒绝理解成欲擒故纵，更别换一种话术继续磨。

6. 转场以后

到了家里或者酒店，基本已经进入最后一个阶段，但这个时候依然不要急，如果你能等到女生主动，那么基本后续会很爽。

安全套提前准备好。问她要不要洗澡。如果她要洗，给她准备一件宽松的大衬衫。

三、约炮以后怎么办

发生关系以后，大概会出现四种情况。

如果你在床上表现不好，女生当天可能就会离开，后面也不会再联系。

这种情况通常没有什么挽回空间。接受结果，换到下一个人，同时认真提升自己的性爱技巧。

你可以直接说明自己不想继续，或者说两个人不太合适。拒绝关系没有问题，羞辱对方没有任何必要。

3. 其中一个人突然动了感情

女生可能突然喜欢上你，男生也可能突然喜欢上女生。

只要一方开始期待恋爱、排他或者更稳定的陪伴，原来的约炮关系就已经发生了变化。

这个情况会复杂很多，需要重新谈两个人到底想要什么。我会在后面单独写一篇，讲清楚怎样“下床”。

4. 发展成长期稳定的炮友

最理想的情况，是你们都喜欢这段关系，也都接受它现在的状态，最后形成长期、稳定、方便的炮友关系。

这个阶段要重新说清楚身体关系是否一对一。如果任何一方出现了新的性伴侣，也要及时告诉对方，重新判断安全风险。

如果你在相处中发现一些异常线索，也要问清楚。

例如她身上有一条可能来自剖腹产的疤痕，这可能意味着她有孩子，也可能意味着她已经结婚。你可以直接问：“你这条疤是怎么来的？”

接不接受是你的权利。听完以后不要攻击她，再诚实决定这段关系是否还在你的接受范围内。

无论最后是否继续，都要维护女生的自尊和快乐。

这是一个男人在约炮过程中最基础的原则。

最后

一段干净的约炮关系只有四条底线：双方自愿、没有金钱、没有虚假的感情承诺、发生关系以后不羞辱对方。

个人魅力决定她愿不愿意靠近你，相同的需求决定这件事能不能发生，事后的分寸决定你们还能不能继续。

别拿恋爱骗性，别拿钱买性，别把拒绝当成欲擒故纵，也别在上床以后突然变成人渣。

去找本来就想要同一种关系的人。
