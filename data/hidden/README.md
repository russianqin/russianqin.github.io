# 隐藏展示的收藏文章

这个目录里**一个文件一篇文章**：`data/hidden/<编号>.json`。文件在，文章就"隐藏展示"；
删掉文件就恢复（或者用博客管理态里的「恢复展示」按钮跳转过来删）。

```json
{
  "slug": "009",
  "title": "文章标题",
  "reason": "内容敏感，暂不公开",
  "hiddenAt": "2026-09-16",
  "page": "/curated/h-9f2c7ab41d08.html"
}
```

- `slug`：文章编号（重号用 `270-2` 这种）；也可以用完整文件名写在 `slug` 里。
- `title` / `hiddenAt` / `page`：构建时自动补全并回写，你手写时只需要 `slug`（和可选的 `reason`）。

隐藏后会发生什么：

- 收藏列表页和站内搜索里都看不到它；
- `sitemap.xml` 不收录；
- 原来的编号地址 `/curated/<编号>.html` 不再生成（线上 404），页面改用不可猜的
  `h-<hash>.html`，且带 `noindex,nofollow`；
- 页面仍然存在，你自己随时可以打开（地址见上面 `page` 字段）。

注意：这是"不在博客上展示"，不是保密——文章仓库本身是公开的。

怎么用：打开 `https://russianqin.github.io/curated.html?admin=1` 进入管理态，
之后收藏列表每条右侧会出现「隐藏」按钮，文章页里也有「关闭展示 / 恢复展示」；
`?admin=0` 退出管理态。
